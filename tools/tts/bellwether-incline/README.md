# Bellwether Incline terrain

Run `python3 source/layout.py` with NumPy installed. The generator writes Wavefront render and collision meshes to `assets/` and the placements in inches to `build/scene.json`. Each native two-state building has a furnished floor mesh and a roofed mesh. State 1 is the interior.

The R1 texture atlas, normal map, ground art and release meshes are in `assets/tts/bellwether-incline-r1/` at repository root. Asset URLs in the Workshop installer are pinned to `ce919941d2bbc64aa442c9a68f5064d10bface9d`.
