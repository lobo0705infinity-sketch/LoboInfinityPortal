# Bellwether Incline R2 terrain

The railway climbs 13.5 inches over a 48-inch horizontal run. The station is built in site coordinates and rotated 90 degrees clockwise for placement on the Infinity table. Each station bank has four flat elevations, six public stairs and one continuous stepped walk beside the rails. The 40 mm objectives use the established Corporate Appropriation assets.

Use Python with NumPy and Shapely 2.1 or higher. Run `python source/layout.py` from this directory to generate the visual and collider OBJ files in `assets` and the matching placements in `build/scene.json`. The packaged material atlases and photographic stone textures are in `assets/tts/bellwether-incline-r2` at the repository root.
