# Infinity map releases

All Infinity map setups must use the approved shared Map Controls panel. Before editing or releasing any Infinity map, read `tts-map-controls-standard/STANDARD.md` and preserve every required control. Do not substitute a menu copied from a historical map. The canonical renderer is `tts-map-controls-standard/standard-broker.lua`.

Every map release must pass the canonical-panel validation and actual-button Lua tests described there. This applies to general maps, Top 40 copies, Aurora variants and community archive setups. No Building Floors / Roofs, My View - Floors or Shared Interiors menu controls. All displayed control labels must use plain supported ASCII text.

A terrain or texture update must retain the standard panel, Turn 180 and separate bright DZ / Exclusion color controls. Preserve approved geometry, assets, states and per-map extras. Do not claim Steam publication or live TTS verification from offline tests.
