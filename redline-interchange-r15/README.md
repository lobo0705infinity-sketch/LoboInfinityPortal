# Redline Interchange R15

- Parcel Office and four service offices: 26.67 mm clear doorways with matching collision, in both states.
- Three Signal Relay House variants rotated 90 degrees clockwise.
- Ground mat rebuilt from the updated building footprints.

Download the [complete table save](Saves/Redline-Interchange-R15-Doors-Rotated-Relays.json) or [deployment bag](Saved-Objects/Redline-Interchange-R15-Doors-Rotated-Relays.json). In GitHub use the Download raw file button. Put the save in Documents/My Games/Tabletop Simulator/Saves, or the bag in Saves/Saved Objects.

Meshes and textures use public immutable HTTPS URLs. Geometry widths, rotations, board bounds, new overlaps and hosted asset bytes were verified. Live TTS loading and multiplayer testing remain untested. Steam Workshop publication is unchanged.
