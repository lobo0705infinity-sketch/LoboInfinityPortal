CLOUDBREAK ARRAY R2
Aurora VII • Turn 5 • Network Node
Harmony City, Harmony Province

INSTALL ON WINDOWS
Extract the entire ZIP and double-click INSTALL-CLOUDBREAK-ARRAY.cmd. If you use a custom location, drag the Tabletop Simulator data folder or its Saves folder onto the installer. It adds two numbered save slots and a copy of the setup bag in Saved Objects. It also opens the Lobo Maps Workshop page.

PLAY
In Games > Save & Load, open Cloudbreak Array R2 - Network Node. The 48 × 48 inch rooftop district is deployed on the Infinity table. Take one civilian for each player from the HVTs bag and use two Modern Classified Objectives per player.

Use the States menu on an individual building to open an interior. State 1 exposes the lowest floor. The highest-numbered state shows the roof. Yellow ladders connect the levels. Pick up loose figures before changing a state that hides the floor beneath them. Each objective appears with the level that supports it.

A / southwest    Cable Drum roof
B / southeast    Transit Arcade, inside level 2
C / northwest    Aerostat Pier roof
D / northeast    Isobar Observatory, exposed level 3 terrace
Primary Node     Switching House roof

Right-click a console to record control after resolving its roll. A player who loses their last relay immediately loses the Primary Node. Open Mission for the briefing and scoring. The Notebook and the included MissionGeist file contain the full campaign scenario.

MOVEMENT AND VISIBILITY
Open air between buildings is impassable. Only Troopers with Terrain (Zero-G) or Terrain (Total) may move through it. All Troopers may use the bridges.

The 11 named clouds are Zero Visibility Zones. In Map Controls, open Map-specific options and select Cloud boundaries to see the footprints and heights. All 28 bridge decks are clear of these volumes. The city and ambient mist below the table are scenery.

MAP CONTROLS
Use Map Rules for the terrain rules, Mission for scoring, and Turn 180 to reverse the map. The shared panel includes Normal / +4 / +8 inch deployment zones, independently selectable DZ and exclusion colors, grid, quadrants, reference tables, Clear Table and Day / Night / Off. Normal deployment is 12 inches deep. The central exclusion band is 8 inches wide.

Day and Night show the same Harmony City skyline above a layer of clouds. Off uses the collection's neutral backdrop.

WORKSHOP COLLECTION
Lobo Maps - Cloudbreak Array Workshop R2 contains 106 setups. It deploys a copy of Cloudbreak on first load and retains the shelf bag for future use. This is the save for Update Workshop on item 3719263238.

REVIEW
Rooftops and Interiors are renders of the exported TTS models. Interiors opens all 16 towers to level 1. Terrain Details shows Glasshouse Quay and the Switching House. Backgrounds shows four views from each spherical panorama. The installer and controls were checked offline. Live multiplayer, Windows execution, and TTS lighting and physics remain for in-game review.
