# Zama save 435 visual and clearance repairs

Repairs both terrain-rich and historical open-ground Zama layouts. Existing texture files and UVs are preserved. Coincident casualty surfaces are separated; figure overlap and label clearance are corrected; wounded commanders retain complete surviving riders and the original fallen-rider artwork.

Offline geometry validation: 51 distinct unit/state meshes; zero intersecting figure bounding boxes; zero coincident triangle pairs; 81 nonoverlapping deployed bases per layout; minimum terrain clearance 0.085 inches. Live Tabletop Simulator import, Windows installer execution, and fresh-cache multiplayer remain untested.
