CLOUDBREAK ARRAY R3
Aurora VII • Turn 5 • Network Node
Harmony City, Harmony Province

INSTALL ON WINDOWS
Extract the ZIP and double-click INSTALL-CLOUDBREAK-ARRAY.cmd. For a custom save location, drag your Tabletop Simulator data folder or its Saves folder onto the installer. It adds two numbered save slots, puts the deployable bag in Saved Objects, and opens the Lobo Maps Workshop page.

PLAY
Under Games > Save & Load, open Cloudbreak Array R3 - Network Node. The rooftop district is already deployed. Take one civilian per player from the HVTs bag and use two Modern Classified Objectives per player. Open Mission for the briefing and scoring. The Notebook and the included MissionGeist file carry the campaign scenario.

EDIT THE CLOUDS
All 23 cloud banks start locked. Right-click the bank itself, open Toggles and turn Lock off. Drag it, or use the Gizmo to set its position, height or rotation. To remove it, select it and press Delete. Gravity is off for the banks, so you can leave one suspended where you place it. Save the table to keep the changes.

Map Controls > Map-specific options > Cloud boundaries traces each bank's current volume. The guide moves with its bank and disappears with it. The default layout keeps all 28 bridge decks clear.

AIR AND VISIBILITY
Open air between buildings is impassable. Only Troopers with Terrain (Zero-G) or Terrain (Total) may move through it. All Troopers may use the bridges.

Cloud banks are Zero Visibility Zones. The distant cloud deck is scenery. The five civilian airships are solid scenery. The Cirrus survey blimp crosses the view from Lift Exchange to Isobar Observatory. Rainband crest cuts another view of Isobar from Rainworks Stack. Greenhouse glazing allows Line of Fire.

BUILDINGS AND OBJECTIVES
Use a building's States menu to open an interior. State 1 exposes the lowest floor. The highest state shows the roof. Yellow ladders connect the levels. Pick up figures before changing a state that hides their floor. On each of the eight glazed greenhouses, a 25 mm base can pass along either wall or between the beds. Each aisle opens at both ends.

Right-click a console to record control after resolving its roll. Losing your last relay also loses control of the Primary Node. Each console appears with its supporting floor.

MAP CONTROLS
Use Map Rules for terrain, Mission for scoring, or Turn 180 to reverse the district. The shared panel includes the Normal, +4 and +8 inch deployment zones, independent DZ and exclusion colors, grid, quadrants, reference tables, Clear Table and Day / Night / Off. Normal deployment is 12 inches deep. The central exclusion band is 8 inches wide.

WORKSHOP COLLECTION
Lobo Maps - Cloudbreak Array Workshop R3 contains 106 setups. It deploys a copy of Cloudbreak on first load and retains the shelf bag. Use this collection save for Update Workshop on item 3719263238.

REVIEW
The Review folder contains the whole-map render, a greenhouse close-up, and two measured rooftop sightlines with views from a standing figure. All three use the released meshes and positions. Installer, controls, saved cloud edits and geometry were tested offline. The Windows executable and the live TTS client remain untested.
